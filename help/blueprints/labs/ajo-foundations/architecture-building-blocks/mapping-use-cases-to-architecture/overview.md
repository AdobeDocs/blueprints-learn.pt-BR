# Mapeamento de casos de uso para a arquitetura

## Objetivos de aprendizagem

Ao final deste laboratório, você poderá:

- Aplicar uma estrutura estruturada de tomada de decisão para avaliar casos de uso de marketing reais
- Identificar os componentes da arquitetura AJO necessários para dar suporte a cada caso de uso
- Selecione o mecanismo de orquestração apropriado — Campanhas ou Jornadas orquestradas — e justifique sua recomendação
- Explicar as decisões de arquitetura corretas para os três casos de uso da conexão 5G e articular os sinais que determinaram cada um
