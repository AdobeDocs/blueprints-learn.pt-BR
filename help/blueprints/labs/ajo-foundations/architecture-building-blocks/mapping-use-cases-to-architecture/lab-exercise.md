# Exercício de laboratório

**Você precisará do seguinte antes de começar:**

- Mapeando Casos de Uso para Pasta de Trabalho de Arquitetura — [Imprimir Pasta de Trabalho Abaixo]
- Caneta, lápis ou marca-texto

Baixar Arquivo — [Mapeando Recursos para Exercício de Arquitetura.pdf](assets/lab-exercise-mapping-capabilities-to-architecture.pdf)

**Para cada um dos três casos de uso do Connection 5G, você vai:**

- Leia o resumo do caso de uso e os materiais do apêndice
- Responda às cinco perguntas sobre o pensamento crítico
- Circule ou destaque os componentes necessários da arquitetura do AJO
- Faça sua recomendação final do mecanismo de orquestração

Analise todos os três casos de uso e prossiga para o vídeo de análise quando terminar.
