# Adicionar atividade de bifurcação

## Objetivo

No próximo conjunto de etapas, você adicionará a atividade Fork à campanha e criará ramificações idênticas dos dados.

## Atividade Bifurcação

A tela com o **Criar público-alvo** configurado é apresentada. Clique em **+** no final do fluxo e adicione uma atividade **Bifurcação** da seção Controle de fluxo

![Adicionar uma atividade de controle de fluxo de bifurcação à tela](assets/add-fork-activity-add-fork-flow-control.png)

>[!NOTE]
>
>Por padrão, uma atividade Fork sempre cria duas ramificações

## Recapitulação

Agora você viu como é fácil usar a atividade Bifurcação na tela da campanha para criar ramificações idênticas dos mesmos dados que fluem para dentro. As ramificações da atividade Fork serão usadas na próxima etapa.

Você pode ler mais [aqui](https://experienceleague.adobe.com/en/docs/journey-optimizer/using/campaigns/orchestrated-campaigns/design-campaigns/fork), se estiver interessado.
