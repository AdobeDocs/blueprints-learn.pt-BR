# Resumo

Neste laboratório, você configurou um fluxo de dados e enviou um evento da Web simulado para a Edge Network usando o Postman para observar como os dados fluem pelo Adobe Experience Platform.

Você validou que o evento foi processado por vários serviços da plataforma, confirmando que um perfil foi criado e qualificado para um segmento no Perfil em tempo real. Você também verificou que o perfil existia na Edge, confirmou que o evento estava armazenado no Data Lake e observou que o perfil ainda não tinha aparecido no conjunto de dados Instantâneo do perfil devido ao processo de atualização em lote agendado.

Por meio dessas etapas, você demonstrou como os eventos se movem pelas camadas do Edge, Perfil em tempo real e Data Lake do Adobe Experience Platform.
