# Perfil em ação

## Pré-requisitos

>[!WARNING]
>
>Os laboratórios abaixo devem ter sido concluídos antes do início deste laboratório

- [Instalação do Postman](../../postman-setup/postman-installation.md)

Se você não concluiu esses laboratórios, faça-o agora antes de continuar.

## Visão geral do laboratório

Neste vídeo, você aprenderá como este laboratório simula uma visita de página da Web do Edge Network ao Adobe Experience Platform e como você validará o perfil, a qualificação de segmento e o evento do data lake resultantes.

>[!VIDEO](https://video.tv.adobe.com/v/3491061/)

## Objetivos de aprendizagem

Neste exercício, simularemos uma visita de página da Web de uma origem do Edge ao Adobe Experience Platform. O que você deveria ir embora depois de tomar este laboratório?

- Criar e configurar um fluxo de dados no Adobe Experience Platform
- Enviar um evento da Web de teste para a Edge Network usando o Postman
- Validar a criação de perfis e a qualificação de segmentos no Perfil em tempo real
- Confirme se o perfil existe no Edge, mas ainda não no conjunto de dados Instantâneo do perfil
- Verifique se o evento foi armazenado no Data Lake
