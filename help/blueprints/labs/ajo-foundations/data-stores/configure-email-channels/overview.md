# Configurar canais de email

## Visão geral do laboratório

Neste vídeo, você aprenderá a criar as duas configurações de canal de email usadas neste laboratório: uma usando um atributo de perfil do AEP e outra usando um atributo de esquema relacional como endereço de execução.

>[!VIDEO](https://video.tv.adobe.com/v/3486540/)

## Objetivos de aprendizagem

- Configurar canal de email usando o atributo de perfil do AEP para campanhas orquestradas
- Configurar canal de email usando atributo de esquema relacional para campanhas orquestradas

Os canais de email serão usados no próximo laboratório para ajudar a entender as nuances de usar uma configuração em vez da outra.
