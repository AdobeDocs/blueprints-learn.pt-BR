# Visão geral do laboratório

## Metas

O objetivo desses laboratórios é preparar você para lidar com os desafios práticos da assimilação de dados. Com esse conhecimento, você poderá lidar, gerenciar e orientar sua equipe sobre as implementações de dados na produção. Assim como a teoria é fascinante, nós vamos passar tempo depurando questões à medida que elas surgem e conectam o que vemos na ferramenta ao dos conceitos mais amplos ensinados neste acampamento.



## O que esperar

Preciso do seu foco. Aqui está o porquê: os dados serão a base de qualquer implementação que você fizer.

Problemas de dados não são fáceis. Os dados são confusos, incompletos, dispersos e difíceis de trazer para o sistema onde você precisa deles. Estes laboratórios foram projetados para apresentar um gostinho desses cenários.

Esse próximo conjunto de laboratórios exigirá atenção e dedicação, pois você estará tocando as entranhas do sistema. Não se espera que você absorva todos os conceitos de uma só vez e, portanto, tire um tempo para encontrar o seu caminho no laboratório.



## Sílabo em poucas palavras

Como você tem esquemas de origem e definiu esquemas de destino no XDM, será necessário conectar os dois esquemas por meio de mapeamentos. Como esse processo requer um campo por mapeamento de campo, você precisará aprender algumas técnicas que aceleram o processo, estando ciente de algumas armadilhas comuns:

- Entender os mapeamentos de passagem
- Corrigir mapeamentos de passagem gerados por AI/ML
- Use a visualização de dados de origem para verificar quaisquer problemas de qualidade de dados

Depois que o mapeamento do schema for configurado, será necessário colocar seu trabalho à prova e depurar erros e avisos:

- Programar uma execução do fluxo de dados
- Marcar um conjunto de dados para o Perfil
- Lidar com erros provenientes de valores ausentes em campos obrigatórios
- Lidar com erros provenientes de erros de incompatibilidade de tipos de dados
- Lidar com erros de assimilação de dados e se recuperar dessas falhas
- Use iterativamente os dados de teste para gerar um conjunto de mapeamento abrangente.
- Verifique e valide os dados assimilados com sucesso.

Você aprenderá os conceitos acima com cenários de assimilação de dados relacionais e não relacionais.
