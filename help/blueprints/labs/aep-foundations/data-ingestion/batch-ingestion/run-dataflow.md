# Executar fluxo de dados

Se tudo estiver bem, clique no botão **Concluir** no canto superior direito para executar o carregamento de dados.

Depois de clicar em **Concluir**, você será redirecionado à tela **Fluxos de Dados**. A criação do fluxo de dados deve levar alguns minutos. A primeira corrida deve começar em alguns minutos.

![Tela de fluxos de dados mostrando o fluxo de dados recém-criado e o status de execução](assets/run-dataflow-dataflows-sources-screen.png)

>[!NOTE]
>
>É necessário atualizar a página continuamente para ver a atualização de status, pois o back-end não envia atualizações para a interface.

>[!NOTE]
>
>Se você ativar todos os alertas, receberá um alerta no navegador, no canto superior direito do navegador, quando o fluxo começar a ser executado e for concluído com sucesso ou falhar
