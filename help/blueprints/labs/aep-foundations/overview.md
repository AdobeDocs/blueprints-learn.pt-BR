# Visão geral

## O que você aprenderá

1. **Relacional para Conversão NoSQL:**
   - Entender a arquitetura, a modelagem e a montagem do Perfil do cliente em tempo real
   - Aplicar a metodologia LID a um cenário fictício para modelar o cliente em tempo real
1. **Experience Data Model (XDM):**
   - Conheça os componentes do XDM e sua relevância para o comportamento do Perfil do cliente em tempo real
   - Prática com construção de esquema usando a interface e a API
1. **Assimilação de dados e criação de perfil:**
   - Diferenciar entre vários armazenamentos de dados no Adobe Experience Platform
   - Saiba mais sobre o processamento de dados para fontes em lote e de transmissão
   - Laboratórios práticos para assimilar dados e criar perfis
1. **Segmentação/Ativação e criação de público-alvo:**
   - Entender os formulários de avaliação de segmento compatíveis com o Perfil do cliente em tempo real
   - Diferenciar funcionalidades de Hub versus Perfil do Edge
   - Criar e ativar públicos-alvo na interface do usuário, incluindo o trabalho com destinos de transmissão



## Público alvo

- Arquitetos de soluções
- Arquitetos corporativos
- Desenvolvedores
- Engenheiros de dados
- Arquitetos de dados



## Experiência ou familiaridade recomendada

- Conceitos de banco de dados (criar, atualizar, excluir)
- Conceitos de modelagem de dados (linhas, campos, chaves etc.)
- Trabalhar com APIs REST
- Compreensão geral do Adobe Experience Platform
- Exposição a CDPs, ad-tech, CRM ou outras pilhas de tecnologia de marketing
