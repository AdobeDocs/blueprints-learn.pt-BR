# Modelagem da interface do usuário

## Mapeamento da origem para o XDM

Obtenha experiência com a tradução do que você coloca em papel e saiba como descobrir e mapear objetos e campos XDM **padrão** versus criar objetos e campos **personalizados**.

O que você vai ficar com:

- Conhecimento da interface do usuário sobre a aparência dos conceitos do Experience Data Model na vida real
- Entenda como objetos e campos são definidos no contexto de **grupos de campos XDM**
- Entenda como usar a interface do esquema para explorar grupos de campos padrão XDM



## Criar XDM via interface do usuário

Executar a criação do esquema de conta do cliente 5G Connection que utiliza o esquema criado usando a metodologia LID

O que você vai ficar com:

- Compreensão básica da interface geral de composição do esquema
- Saiba como adicionar grupos de campos padrão XDM a um esquema
- Saiba como remover campos desnecessários de grupos de campos padrão XDM
- Ser capaz de criar e usar grupos de campos personalizados em um esquema
- Saiba como salvar com frequência durante o desenvolvimento do esquema 😄
- Entender as diferenças entre enumerações e valores sugeridos



## Configuração do para perfil

Saiba mais sobre as etapas necessárias para configurar um esquema para uso com o Perfil de cliente em tempo real, desde a marcação de identidade até o estabelecimento de relações para esquemas de pesquisa.

O que você vai ficar com:

- Ser capaz de marcar um campo como uma identidade ou identidade principal
- Criar uma relação entre dois esquemas
- Entenda o motivo para **testar** o esquema antes de habilitar para Perfil
- Entenda o **esquema de união** e veja-o visualmente em ação
