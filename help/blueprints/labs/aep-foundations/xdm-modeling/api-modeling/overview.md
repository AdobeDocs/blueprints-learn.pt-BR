# Modelagem de API

## Visão geral do laboratório

Trabalhar com as APIs do Experience Platform é essencial para entender como automatizar e operacionalizar vários recursos da plataforma. Definir esquemas e entender como os dados são descritos por esses esquemas é uma das primeiras coisas que um cliente fará no Adobe Experience Platform ao definir sua arquitetura de dados.

Este laboratório apresentará a você a experiência de design do esquema do Adobe Experience Platform utilizando apenas as APIs. Você aprenderá a criar seus próprios esquemas utilizando componentes XDM existentes, adicionando suas próprias personalizações no XDM e identificando e criando vários descritores de identidade para usar com o Perfil do cliente em tempo real.

## Objetivos de aprendizagem

Ser capaz de criar um esquema utilizando apenas as APIs do Experience Platform por meio de uma variedade de componentes essenciais XDM, como:

1. Classes
1. Grupos de campos
1. Descritores
   1. Identidades (incluindo Primárias)
   2. Relacionamento
   3. Referência
