# Criar esquema

## Assembly de esquema

Todos os esquemas como parte do XDM são compostos da mesma maneira.  Um esquema é sempre composto de apenas uma classe e um ou mais grupos de campos. Além disso, a classe de um esquema determina como outros sistemas na Experience Platform interpretarão os dados (ou seja, como baseados em registro ou séries de tempo).

![Diagrama mostrando um esquema composto por uma classe e um ou mais grupos de campos](assets/overview-schema-assembly.jpeg "Assembly de Esquema")
