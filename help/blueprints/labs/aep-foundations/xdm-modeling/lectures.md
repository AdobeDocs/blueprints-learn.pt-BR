# Palestras

O XDM (Experience Data Model) é a estrutura padronizada da Adobe para organizar dados de experiência do cliente em diferentes sistemas. Ele garante que os dados de várias fontes — como sites, aplicativos e CRMs — sejam estruturados de forma consistente, facilitando a unificação, a análise e a ativação em tempo real. Essa consistência é essencial para criar perfis precisos do cliente, permitir experiências personalizadas e oferecer suporte a insights orientados por IA no Adobe Experience Platform.
